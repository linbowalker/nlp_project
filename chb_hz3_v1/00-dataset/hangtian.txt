2023.11–2024.12 航天内部平台有害内容智能检测系统（涉密合规版）
项目描述：
面向航天科研单位内网协作平台（邮件、论坛、即时通信等），构建双轨制高风险文本识别系统。系统针对本公司人员采用完全本地化、无外联的深度学习模型（FastText / BERT / 蒸馏模型），确保核心机密数据不出域；针对外协人员处理的脱敏非敏感内容，允许调用国产大模型 API（DeepSeek-V3）进行辅助分类。系统精准识别违规外联诱导、冒充身份指令、非法金融活动、内部煽动言论、非工作敏感内容、机密信息泄露（含型号、参数、任务等关键词）等6类高危行为，有效支撑内部信息合规审计与安全事件预警，严格满足国家涉密信息系统安全规范。

项目职责：

安全需求对齐与标签体系构建：
联合保密办与网络安全中心，基于真实内网语料定义6类高风险内容标准，其中“机密信息泄露”类别专门覆盖国家秘密、航天型号代号、关键技术参数、任务时间节点、试验数据等关键词；
完成8万余条内部文本的脱敏、标注与审核，确保标签体系贴合航天业务语境。
本地模型自主研发与部署（本公司人员使用）：.
实现 Random Forest + TF-IDF 基线模型（Macro-F1: 84.2%）；
构建 FastText 字符级与词级别双路径模型，使用 jieba 分词 + autotuneDuration=300 自动调参，F1 提升至 91.0%；
微调 BERT-base-chinese（本地加载预训练权重），针对短文本、拼音变体、谐音绕过等对抗样本优化，在内网测试集达 92.5% F1；
应用 PyTorch 动态量化（torch.quantization.quantize_dynamic），将 BERT 模型体积压缩 40%，推理速度提升 2 倍（仅 CPU）；
实施 知识蒸馏（Teacher: BERT → Student: BiLSTM），使用 KL 散度 + 温度 T=2 + 软硬标签加权（α=0.7），在 CPU 环境下实现 89.3% F1，为边缘部署预留路径；
通过 Flask + Streamlit 在内网部署 API 与可视化界面，响应时间 ≤200ms，全程物理隔离，无任何外网访问。
外协辅助分类通道（外协人员使用）：
针对外协人员仅能接触的脱敏非敏感文本（如公开论坛留言、非任务类沟通），设计 DeepSeek-V3 零样本分类流程；
构建结构化 Prompt，限定输出为6类标签之一（如 输出：机密信息泄露），确保格式可控；
所有 API 调用经内网安全网关代理，不直接暴露密钥，调用日志全量审计；
在抽样测试中，DeepSeek-V3 准确率达 86.3%，用于辅助初筛+人工复核，不作为最终决策依据。
安全合规闭环管理：
本地模型与数据不出内网，外协通道仅处理脱敏文本；
所有代码、模型、日志通过单位信息安全审计，满足“分级管控、最小权限、过程可溯”要求。
项目成果：

本地模型 Macro-F1 达 92.5%，对新型钓鱼话术与身份伪造文本召回率提升 35%；
系统上线后累计拦截高风险内容 1.2 万余条，其中 机密信息泄露类占比 18%，违规信息传播率下降 85%；
外协辅助通道提升非敏感内容审核效率 40%，人工复核量显著降低；
支撑某重点型号任务期间内网通信用零安全事故，获单位“网络安全创新应用奖”；
被纳入《航天科研单位内部信息内容安全技术指引（2024版）》，作为标准组件推广至多个院所。
